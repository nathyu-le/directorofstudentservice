# Thuật ngữ tài liệu

PRD: yêu cầu sản phẩm; FR: hành vi có mã; AC: điều kiện nghiệm thu; TC: test case; E2E: kiểm tra luồng xuyên module; NFR: yêu cầu phi chức năng; MET: phép đo mục tiêu; PM/BA: quản lý và phân tích; BE: backend; FE: frontend; QA: kiểm thử/tài liệu. Bug khác TC: một case Fail dẫn đến lỗi cần sửa, không xóa case gốc.
